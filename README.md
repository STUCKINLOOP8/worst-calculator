# 🧮 CALC-U-TORTURE 3000 (Playable Comedy Edition)

> *A delightfully terrible, retro-styled calculator parody that is actually playable and fun to use!*

## ✨ Features

- **⚡ Instant, Snappy Clicking**: Every key responds immediately with retro sound effects.
- **⌨️ Keyboard Support**: Use your physical numpad, numbers, Backspace, Enter, and Escape keys.
- **🎨 Mismatched Typography**: Every button uses conflicting, terrible fonts (Papyrus, Impact, Comic Sans, Trebuchet, Georgia).
- **🪰 The Screen Fly**: An animated insect crawling on the LCD screen (click it to shoo it away!).
- **💨 Dodging Equals Button**: The `=` button dodges your mouse once before allowing you to click it.
- **⚡ Quantum Calculation Sequence**: Fast loading bar with a comedic 99% crash and a 1-click philosophical CAPTCHA.
- **📎 Sarcastic Calc-y**: Gives unhelpful advice without getting in your way.

## 🚀 Running Locally

Open `index.html` directly in your browser or run:

```bash
python -m http.server 8080
```

Then visit **[http://localhost:8080](http://localhost:8080)**.
